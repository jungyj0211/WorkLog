- 이상데이터 수령(필링크)
- **연구 실적 관련 논문 작성 중**
  - **논문 흐름**
    - SMPS 데이터 측정
    - 비지도학습, 수명예측 모델(Tcase 사용, 아레니우스 모델), 누적 손상 모델?(마이너 법칙) 사용
      - SMPS 내부 몰딩으로 인해 내부 부품에 인가 또는 출력되는 전압, 전류를 측정할 수 없음
      - SMPS 케이스 온도(Tcase)를 사용하면 아레니우스 모델과 제품의 레퍼런스를 통해 수명 예측이 가능
      - 보다 정밀한 수명 예측이 필요한 경우 누적 손상 모델(마이너 법칙)을 사용
        - Tcase가 0도에서 80도로 서서히 변화할 것이며 온도 값에따른 손상도가 다를 것이므로 이를 적용하여 더 정밀하게 측정 가능하다는 말임
      - 그럼 비지도 학습은?? 
        - 지금까지 내용은 기존에 연구되던 것들이고 AI 모델(비지도학습)의 결과를 보조하는 역할이 좋을지 AI 모델이 기존 연구 내용을 보조하는 역할이 좋을지..음..
        - 현재 상황(이상데이터 없음, 실제 필드 데이터 당연히 없음, SMPS에서 측정 가능한 데이터 제한적)에서는 비지도 학습을 보조로 사용하는게 현실적일듯?
        - 누적 손상 기반 수명 예측(아레니우스, 마이너) + 비지도 학습(이상감지 등) 조합으로 활용
        - 비지도 학습에 대한 내용 추가하고 어떻게 활용되는지 추가하면 전체적인 시스템 구성이 나올꺼 같음
    -  서론 보충(why?)
        - 비지도는 왜 서브인가? Tcase가 필요한가? 이런 내용은 서론에 작성
        - 왜 SMPS 데이터를 사용하는가?에 대한 의문..음..
          1. SPMS는 모든 전자제품에 사용됨에 따라 해당 기술의 범용성이 크다?
          2. SMPS는 직접적으로 부하를 받는 부분이며, 따라서 동작부?의 고장보다 전원부의 고장이 먼저 발생할 확률이 큼?
          3. 아니면 그냥 타겟을 좁혀서 LED 조명에 대한 예지보전 연구 진행인데 LED 수명이 개길다. 그래서 SMPS의 수명 예측으로 접근했다?
          4. 진짜 아니면 그냥 아무말 없이 SMPS에 대한 연구인척 하면됨?
  - **서론 초안 :**
  본 연구는 옥외 조명 등 장주기 제품의 예지보전을 목표로 한다. LED 조명 자체는 수명이 길고 체감 열화가 늦게 드러나는 반면, 전원 변환부(SMPS)는 열·전기 스트레스가 집중되는 모듈로 케이스온도(Tcase), 출력 전압/전류, 초음파(표현 수정 필요)를 비침습적으로 상시 측정할 수 있다. 측정한 데이터를 기반으로 Tcase에 기반한 아레니우스–마이너 누적손상으로 기본 RUL을 산출하고, 동시에 비지도 모델로 비열적 이상과 운전상태 변동을 감시해 조기 경보 및 보정을 수행한다. 

  - **본론 부분 :**
  연구 내용 작성, 순서도, 구성, 이런것들. 
    - 누적손상기반 수명예측 관련 내용(메인):
      - 수명예측 : 아레니우스 모델
      - 누적손상 : 마이너 법칙
      - Tcase 기반 누적 손상 수명예측, 각 수식에 활용방법정도?

    - 비지도학습 관련 내용(보조):
      - PCA(주성분 분석) + MSPC(다변량 통계적 공정 관리) 알고리즘 사용
      - PCA는 데이터의 핵심적 패턴 요약(데이터 차원 축소), 여러 변수들이 가진 정보를 잘 설명하는 새로운 주성분을 찾는 것
      - MSPC는 PCA 활용하여 정상 상태 데이터 학습, 새로운 데이터가 정상 상태를 벗어났는지 감지, 정상과 비정상의 판단을 데이터 통계적 특성 기반으로 함
      - 군집이 필요한가? 있으면 좋긴하다. 없다고 안좋은것도 아님.
      - 군집은 이상 데이터 식별에 효과적. 결과 해석 단계에서 MSPC 처리 이후, 활용 가능할 듯.

    - 비지도학습 모델이 어떻게 서포트하는지에 대한 내용이 필요. 이거 없으면 의미없음, 명확하게 누구나 납득할수 있도록. 아~ 그래서 필요한거구나~ 좋을듯? 이느낌 나도록.

  
  - **결론 부분에 들어가면 좋을 듯한 표현 :**
  이 접근은 LED 조명에 우선 적용되지만, SMPS가 광범위한 전자제품에 공통으로 포함된다는 점에서 확장성을 갖는다.
