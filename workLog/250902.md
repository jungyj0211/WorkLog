  ❗학습 방법에 따른 차이점(파인튜닝 vs 스크레치)
  > - 파인튜닝(fine-tuning) 
  >   - 대규모 데이터(COCO etc.)로 이미 학습된 프리트레인 가중치를 초기값으로 불러와, 내 데이터로 "추가 학습"하여 도메인에 맞게 미세조정.
  >   - 그러니까, 이미 학습된 모델에 데이터를 추가하여 학습하는 방법
  >   - 초기값: 프리트레인 가중치(기존 학습된 가중치 사용)
  >   - 장 점: 데이터가 적어도 효과적이며 학습이 빠름
  >   - 단 점: 프리트레인 도메인과 너무 다르면 성능에 제한이 될 수 있음
  > ```bash
  >   # model=yolo11s.pt 가 COCO 프리트레인
  >   yolo task=detect mode=train model=yolo11s.pt data=internal.yaml epochs=60 
  > ```
  > - 스크레치(from scratch)
  >   - 무작위 초기 가중치(빈 모델)에서 처음부터 내 데이터로 학습
  >   - 초기값: 랜덤
  >   - 장 점: 설계 자유도가 높음
  >   - 단 점: 데이터/시간/리소스가 많이 필요하며, 성능 리스크가 큼
  > ```bash
  >   # .yaml은 구조만 주고 가중치는 무작위 초기화
  >   yolo task=detect mode=train model=yolo11s.yaml data=internal.yaml epochs=60
  > ```
  > 
  ❗파인튜닝 중 혼합학습(기존 데이터 + 추가 데이터) 필요?
    - 무조건 합치지 말고, 필요할 때 소량만 전략적으로 섞기
    - 추가 학습 데이터만으로 충분한 상황이라면 굳이 기존 프리트레인에 사용한 데이터를 추가하여 학습할 필요는 없음
    - 언제 같이 학습 함? 추가 데이터의 클래스 중 샘플 수가 매우 적을 때, 추가 데이터가 너무 많아 기존 학습 데이터를 망각할것 같을 때(일반화).. 이럴때 추가하여 학습 진행
    - 혼합학습을 진행함에 있어 주의해야할 것은 기존 데이터가 추가 데이터보다 많을 경우, 의미가 희석될 경우가 있기에 추가데이터의 60%~80% 정도로 구성하여 혼합 할 것
