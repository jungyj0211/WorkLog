## ▶️ VL
- 포즈추정 라벨링 진행
- key points
  - 왼쪽 어깨(LS) 1, 오른쪽 어깨(RS) 2, 왼쪽 팔꿈치(LE) 3, 오른쪽 팔꿈치(RE) 4, 왼쪽 손목(LW) 5, 오른쪽 손목(RW) 6, 왼쪽 골반(LH) 7, 오른쪽 골반(RH) 8, 왼쪽 무릅(LK) 9, 오른쪽 무릎(RK) 10, 왼쪽 발목(LA) 11, 오른쪽 발목(RA) 12
- 스켈레톤 엣지
  - 어깨–어깨: (LS–RS)
  - 엉덩이–엉덩이: (LH–RH)
  - 몸통: (LS–LH), (RS–RH)
  - 팔: (LS–LE–LW), (RS–RE–RW)
  - 다리: (LH–LK–LA), (RH–RK–RA)
- 라벨링 규칙
  - v=2 (보임): 점이 명확히 보임 → 정확하게 정확하게 포인팅
  - v=1 (가림/추정 가능): 안 보이지만 뼈대/이웃 점으로 위치를 합리적으로 추정 가능? → 추정 좌표 찍고 v=1.
  - v=0 (미표기): 전혀 추정 불가 → 이 점은 라벨 생략(x=y=0, v=0).
  ❗CVAT 에서 v = 1 or 0 처리는 Occluded(1), Outside(0) 토글로 처리
  ![alt text](/image/pose_kps_02.png)
- 상황별 가이드
  - 문턱/난간에 발목 가림: 무릎·엉덩이와 바닥 라인으로 위치가 그려지면 v=1, 전혀 감 안 오면 v=0.
  - 계단 난간에 무릎 가림: 허벅지·종아리 방향으로 무릎 위치가 예상되면 v=1, 아니면 v=0.
  - 사람이 부분적으로 프레임 밖: 밖으로 사라진 관절은 v=0. (사람 자체가 나갔으면 트랙을 outside로)
  - 왼/오 헷갈림: 항상 사람 기준 좌/우. 안 보이는 쪽도 좌/우는 유지. 헷갈리면 해당 점은 v=0로 남겨.
  - 여러 프레임 연속 가림: 보이는 프레임들만 키프레임으로 정확히 찍고, 사이 구간은 필요 시 보간/추정(v=1) 또는 미표기(v=0).

## ▶️ ON
- 전류 단위 이슈
  - CC6900SO-20A 사용. 전류를 아날로그 전압(0[V] ~ 5[V])로 바꿔주는 센서
  - 측정 시 전류값이 아닌 레벨값[V] 출력, default 2.5[V](전류 0[A])
  - 100[mV] / [A] 
    $$100\ [mV] = 1\ [A], \quad 10\ [mV] = 0.1\ [A]$$
    - CC6900SO-20A(센서) 데이터시트 기준 
    25℃(정온) 출력 오차 ±0.2 [A], 
    -40℃ ~ 125℃(전온) 출력 오차 ±0.6 [A],
    - 실측(필링크) 기준 : 출력 오차 ±0.5 [A]
    <br>
  - 참고(SMPS 전류전압 정상범위 측정표_필링크)
![alt text](/image/SMPS%20전류전압%20정상범위%20측정표.png)
    <br>
- 전압 관련 이슈
  - 전달받은 데이터 파일에서 전류·전압 컬럼명이 역매핑되어 표기(vi_v ↔ vi_i) 
  - 실제 전압값 구하기 위해 다음의 전압분배 공식 사용
    ![alt text](/image/전압분배회로.jpg)
    $$V_{out} = \frac{R_2}{R_1 + R_2} \times V_{cc} $$
  - 실제 저항 값 적용
    $$V_{out} = \frac{51}{1051} \times V_{cc}, \quad\quad V_{cc} = \frac{1051}{51} \times V_{out}$$
